### Install

1. Download the file above and double-click it.
2. Windows may say **"Windows protected your PC"**. This appears because the app isn't code-signed yet. Click **More info**, then **Run anyway**.
3. Follow the installer. It installs Microsoft Edge WebView2 automatically if the computer doesn't already have it.
4. Open **DogForce Security Services** from the Start menu and sign in with your usual DogForce login.

If you already have an older version, just run this installer; it replaces the old one.
